## 大前提：命令行工具（CLT）
安装命令行工具：
```bash
xcode-select --install
```
只提供编译器、SDK头文件，很小，只是开发工具集，不是完整Xcode




## Python
先看看 macOS 自带的 Python3：
```bash
$ which python3
/usr/bin/python3     # <== 系统级
$ python3 --version
Python 3.9.6        # <== 都 2026 年了，还 3.9.6，老成什么样了？
```
> ⚠️ 注意： 不要用系统自带的Python进行 `pip install`，容易污染系统。

苹果故意锁死 3.9.6 这个老版本，原因有两个：
1. **系统内部组件依赖它**：macOS 后台不少系统脚本、工具要靠这个内置Python跑；
2. **苹果策略：系统Python只给系统自己用，不面向用户开发**，不打算给你升级，也不能直接升级。

如果需要新的版本，用 Homebrew 安装：
```bash
brew install python
```
brew装的Python会放到 `/opt/homebrew/bin/python3`，和系统 `/usr/bin/python3` 完全隔离，互不干扰。
装完之后，终端优先用新版本，你可以用 `which python3` 确认路径变化。

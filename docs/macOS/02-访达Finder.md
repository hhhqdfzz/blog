## 切换某扩展名文件的默认打开方式
直接右键 → 打开方式，只是单次临时打开，不会改默认，这一节着重解决这个问题。
### 一般方法
1. 访达里随便找一个这个后缀的文件
2. `Control + 点击`（右键）→ **显示简介**
3. 展开【打开方式】下拉菜单，选你想要的程序
4. 重点！点下方 **全部更改…**
5. 弹窗确认【继续】，之后所有同后缀的文件，双击都会用这个App打开
> ⚠️ 注意：macOS 不是单纯按后缀匹配，它是按「文件类型UTI」，少数情况：同样后缀但来源不同，系统识别成两种类型，这个时候这个操作不会覆盖全部，这种情况要用下面的命令行工具。

### 🧪 进阶：命令行工具
图形界面搞不定的时候（上面说的UTI分裂问题）用这个，适合批量/脚本。
1. 安装 `duti`
    ```bash
    brew install duti
    ```
2. 查目标App的Bundle ID
    比如IINA这个App：
    ```bash
    osascript -e 'id of app "IINA"'
    ```
    会输出类似 `com.colliderli.iina`
3. 绑定扩展名给目标App
    比如 .mp3，
    ```bash
    duti -s com.colliderli.iina public.mp3 all
    ```
    查看当前这个后缀绑定：
    ```bash
    duti -l public.mp3
    ```

## 显示隐藏文件或目录
快捷键 ⇧⌘.（最后面的点不是句号！是快捷键组成部分之一）

有时可以在显示的设置（⌘J）里找，例如在家目录的显示设置中，可以勾选显示资源库。

如果只是想临时显示资源库，请在访达的顶部菜单【前往】中，按住 Option（Alt），菜单里就会多出【资源库】，点一下直接进入。


## 快捷方式
Windows 的快捷方式是 .Ink 文件，右键菜单里可以创建；Linux 的快捷方式是软链接，创建方式为 `ln -s`；而 macOS 的快捷方式有两种：`ln -s`软链接（后文简称软链接）和访达的替身。

软链接不能被访达读取，只在命令行中可用。能被访达读取的快捷方式是替身，创建方式为，选中文件或目录，右键菜单里旋转制作替身，或选中文件或目录后按 ⌘E。

如果快捷方式的目的是在命令行里便于访问，那么做成软链接；如果是想方便在图形界面点开，那么将快捷方式做成替身。


## 🔍 搜索：三种机制，不是什么都搜得到
### Spotlight 搜索
#### 设置中的排除列表
“设置 → 聚焦（Spotlight）”可以排除某类文件被搜到。
#### 依靠系统索引，跳过很多库目录
macOS 有一套内置硬编码排除规则，对一些目录，例如`~/Library` 的 `Containers`、`Application Scripts` 等目录，**不会被 Spotlight 主动收录进索引**。目的：
- 这些是App内部数据，不是给你手动浏览修改的
- 防止 Spotlight 索引大量细碎缓存文件，拖慢系统

如果想强制让 Spotlight 索引这些目录，可以用如下命令重建索引：
```bash
sudo mdutil -E /
```
⚠️ 但这样做副作用很大，并不推荐：
- 索引会变得巨大，后台长时间疯狂读写磁盘、耗电；
- 大量缓存、日志文件混进搜索结果，搜索结果杂乱；
- macOS 版本更新后，经常会重新恢复这套内置排除规则，过段时间又搜不到。

### 访达搜索
如何到达隐藏的路径？或者在隐藏路径里找文件？
1. 访达 `Shift+Command+G`，直接粘贴路径，你就能看到这些文件夹，**手动是可以进去的，只是搜不到**。
2. **实时遍历搜索（不走索引）**：**先进入这个文件夹，再在当前窗口内搜索**，访达会直接扫描磁盘，不需要索引，就能搜到里面文件

### 终端内搜索
`find` 时，为什么 `sudo` 了还是显示`Operation not permitted`？

它们不是普通的读写权限，而是基于macOS的两套保护机制：
1. **SIP 系统完整性保护（System Integrity Protection）**：保护系统分区 `/System`，防止篡改系统文件
2. **TCC 隐私保护**：保护用户数据，每个App/进程有独立数据隔离，哪怕是root（sudo）也不能随便闯入其他App的私有沙盒

👉 macOS 中`sudo` 并没有万能超级权限！
这和传统Linux完全不一样：Linux的root几乎无限制；macOS的root被SIP+TCC双层枷锁锁住。

**不存在一条设置，一键让命令行拥有Linux root那种自由遍历全部目录的能力。**

关闭SIP简要步骤（仅作了解，不推荐长期关闭）：
1. 重启，看到苹果的logo后，长按电源键直到出现选项 → 进入恢复模式
2. 打开终端，执行：`csrutil disable`
3. 继续重启，系统以 SIP 关闭的情况下运行。如果要开启，请在恢复模式中执行 `csrutil enable`

> 关闭SIP会失去很多系统安全保障，系统更新后经常自动重新开启
> 关闭SIP之后依然还有TCC隐私限制，不是万能的！

## 软件来源
### App Store
这是苹果官方最权威的软件来源，都通过了苹果的签名认证，绝对安全，没什么好说的。

### .dmg 文件
很多开发者交不起苹果昂贵的认证费用，没有把自己的作品上架到 App Store，而 .dmg 文件就是他们作品的形式之一。

.dmg 文件，相当于 Windows 的 .iso，打开时会以磁盘的形式挂载。软件安装完后需要将 .dmg 文件推出，可以右键选“推出”，也可以用快捷键 ⌘E。

.dmg 可能会受到[苹果 Gatekeeper 机制](https://juejin.cn/post/7610328473442598912)的拦截，可以在使用前解除：
```bash
sudo spctl --master-disable
```
然后到 “设置 -> 隐私与安全性 -> 允许以下来源的应用程序” 中选择 “任何来源”，再使用 .dmg 安装包。

不建议长期关闭 Gatekeeper，用完 .dmg 后重新打开：
```bash
sudo spctl --master-enable
```

### Homebrew
根据[官网](https://docs.brew.sh)的提示，安装方法为
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
#### 使用方法
```bash

  brew

  Homebrew - 一个 macOS 和 Linux 的包管理器。
  此命令也有关于其子命令的文件，例如：install。
  更多信息：https://docs.brew.sh/Manpage。

  安装最新稳定版本的软件包或安装包：

    brew install 软件包

  列出所有已安装的软件包和安装包：

    brew list

  升级已安装的软件包或安装包（如果未指定，则升级所有已安装的软件包或安装包）：

    brew upgrade 软件包

  从 Homebrew 源代码仓库中获取 Homebrew 和所有软件包及安装包的最新版本：

    brew update

  显示有更新版本可用的软件包和安装包：

    brew outdated

  搜索可用的软件包（即包）和安装包（即本地 macOS .app 包）：

    brew search 软件包名称

  显示有关软件包或安装包的信息（版本、安装路径、依赖项等）：

    brew info 软件包

  检查本地的 Homebrew 安装中的潜在问题：

    brew doctor

```
#### 目录结构
使用 `tree $(brew --prefix) -L 2`即刻查看，下面是做过处理后的结果，仅列了主要文件和目录：
```bash
/opt/homebrew/
├── Cellar/         # 放formula类软件（运行在CLI）本体的地方
│   └── python/     # 每个软件可以并存各种版本
│       ├── 3.11.8/
│       └── 3.12.3/
├── /Caskroom
│   └── maccy       # 放 cask类软件（运行中GUI）本体的地方
│       └── 2.8.0/
│           └── Maccy.app -> /Applications/Maccy.app    # cask类软件的可执行文件一般为 *.App，往往链接到 /Applications 目录
├── bin/  sbin/             # formula类可执行文件的软链（PATH 里的入口，本体在 Cellar）
├── opt/             		# 软链，指向各软件的当前版本目录
├── etc/  var/              # 少数软件的配置文件 / 运行时数据
├── lib/  include/  share/  # 依赖库、头文件、共享资源
├── Library/Homebrew/       # Homebrew 自身
└── docs/                   # Homebrew相关文档、开发规范
```
`/opt/homebrew/bin` 是brew安装的formula类软件通往终端的窗口，排在 `PATH` 变量的最后，所以不会抢在系统的 `/usr/bin `或 `bin` 前面而污染系统。


## 把软件卸干净
- 对于Homebrew 安装的软件，直接用 Homebrew 即可。
- 对于 App Store 或 .dmg 安装的软件，优先使用 AppCleaner、CleanMyMac 等第三方工具进行卸载。

软件的安装目录往往分布在：
```
~/Library/Application Support/
~/Library/Caches/
~/Library/Preferences/
~/Library/Logs/
~/Library/Saved Application State/
```
但也有可能分布在其他目录，手动找固然可行，但每个App都这样做的话，成本过高。用上面提到的第三方工具卸载，效果往往相当不错，但不能保证百分百清理干净，因为有的开发者写得很不规范，第三方工具找不到那些由于开发不规范导致的残留。对于以后可能会卸载掉的软件，多留意它的安装目录，部分安装程序会有相应输出。

有的 App 卸载不了，这是因为苹果的 SIP（系统完整性保护）机制做了保护。不要强行卸载这些 App，否则影响系统的正常运行，得不偿失。

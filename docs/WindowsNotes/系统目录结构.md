# {{ $frontmatter.title }}

Windows 系统与用户目录结构可以理解为一个“多用户、多层级、分区独立”的文件系统。它与 Linux 的目录结构并不是一一对应，但可以将常见目录与 Linux 中的相近概念对照。

## 1. Windows 根目录

Windows 通常安装在磁盘根目录，例如 `C:\`。根目录下主要包含系统文件和系统级目录。

```text
C:\
├── Windows
├── Program Files
├── Program Files (x86)
├── Users
├── ProgramData
├── PerfLogs
└── temp
```

### `Windows`

Windows 操作系统的核心文件目录，包含内核、驱动、系统组件和部分系统工具。

相当于 Linux 中的 `/boot`、`/usr`、`/lib` 等目录，但并非单独一个目录；它主要用于保存操作系统本身。

### `Program Files`

安装 64 位应用程序的默认目录，通常是 `C:\Program Files\应用名`。

相当于 Linux 中的 `/usr/bin`、`/usr/lib`、`/opt` 等目录中的软件安装目录。一般用于安装系统级应用。

### `Program Files (x86)`

安装 32 位应用程序的目录。较新的 Windows 版本通常将 32 位程序放在这里。

相当于 Linux 中的 `/usr/lib32`、`/opt` 等目录中的兼容软件目录。

### `Users`

所有用户的主目录集合。通常包含每个用户的个人文件、配置和桌面等内容。

相当于 Linux 中的 `/home`。

### `ProgramData`

所有用户共享的应用程序数据目录。程序通常会将需要跨用户访问、或不属于单个用户的数据保存到这里。

相当于 Linux 中的 `/var` 或 `/var/lib`，尤其接近 Linux 中程序共享状态数据的存放方式。

### `PerfLogs`

系统性能日志和诊断日志目录。

相当于 Linux 中的 `/var/log`。

## 2. 用户目录

每个 Windows 用户通常有一个独立的用户目录，位于 `C:\Users\用户名`。

```text
C:\Users\用户名
├── Desktop
├── Documents
├── Downloads
├── Music
├── Pictures
├── Videos
├── AppData
├── OneDrive
└── .config（部分环境下可能存在）
```

用户目录下的内容与 Linux 用户的家目录相类似。

相当于 Linux 中的 `/home/用户名`。

### 桌面、图片、音乐、视频等目录的路径

Linux 通过 `~/.config/user-dirs.dirs` 配置（XDG 用户目录），体现了“文本为王”。Windows 的对应物是 **注册表中的 Known Folder**，同样可以用命令行修改：

- 查询某个目录的真实路径：

    ```powershell
    [Environment]::GetFolderPath('Desktop')        # 桌面
    [Environment]::GetFolderPath('MyPictures')     # 图片
    [Environment]::GetFolderPath('MyMusic')        # 音乐
    [Environment]::GetFolderPath('MyVideos')       # 视频
    [Environment]::GetFolderPath('Personal')       # 文档
    ```

- 列出所有 Known Folder：

    ```powershell
    [Enum]::GetNames([Environment+SpecialFolder])
    ```

- 修改路径：改注册表键              `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders` 中的对应值（`Desktop`、`My Pictures`、`My Music`、`My Video` 等，REG_EXPAND_SZ 类型），然后把目录实际移动过去，注销重登（或重启 explorer）生效：

    ```powershell
    Set-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders' -Name 'Desktop' -Value 'D:\UserData\Desktop'
    ```

    `user-dirs.dirs` 与 Windows 的对应关系：
    - `XDG_DESKTOP_DIR` → `Desktop`
    - `XDG_MUSIC_DIR` → `Music`
    - `XDG_PICTURES_DIR` → `Pictures`
    - `XDG_VIDEOS_DIR` → `Video`
    - `XDG_DOCUMENTS_DIR` → `Documents`
    - `XDG_DOWNLOAD_DIR` → `Downloads`


### `AppData`

保存用户级应用配置、缓存、数据和运行时文件。

```text
C:\Users\用户名\AppData
├── Local
├── LocalLow
└── Roaming
```

它类似于 Linux 中用户家目录下的隐藏配置目录，例如：

- `~/.config`：应用配置
- `~/.local/share`：应用数据
- `~/.cache`：缓存
- `~/.local`：用户级本地数据

#### `AppData\Roaming`

保存用户在不同计算机之间需要保留的配置数据。通常在 Windows 域或使用 Microsoft 账户登录时，同步到其他电脑。

相当于 Linux 中的 `~/.config` 或 `~/.local/share`。实际上它更接近“跨设备同步的用户配置”。

#### `AppData\Local`

保存仅当前计算机有效的应用数据，例如缓存、日志、临时文件和本地数据库。

相当于 Linux 中的 `~/.local`、`~/.cache` 和各应用独立的配置或数据目录。

#### `AppData\LocalLow`

用于低权限或低特权应用的本地数据。主要供浏览器、插件或低权限程序使用。

可以理解为 Linux 中更受限制的用户级应用数据目录，例如带有较低权限要求的缓存或配置位置。

## 3. Windows 系统目录

```text
C:\Windows
├── System32
├── SysWOW64
├── WinSxS
├── SystemApps
├── Fonts
├── Temp
└── SoftwareDistribution
```

### `System32`

Windows 系统的核心动态链接库、驱动、执行程序和系统工具目录。

相当于 Linux 中的 `/usr/lib`、`/lib` 和 `/usr/bin` 等系统级目录组合。

### `SysWOW64`

存放 32 位系统组件和兼容库，用于兼容旧版 32 位程序。

相当于 Linux 中的 32 位系统库目录，例如部分 32 位兼容组件。

### `WinSxS`

Windows 组件存储目录，包含系统组件的安装、更新和回滚资源。

相当于 Linux 中的包管理器缓存、软件仓库组件或系统组件备用文件。

### `Fonts`

系统字体文件目录。

相当于 Linux 中的 `/usr/share/fonts`。

### `Temp`

系统临时文件目录。

相当于 Linux 中的 `/tmp`（有时也会使用 `/var/tmp`）。

## 4. Windows 与 Linux 的对应关系

| Windows 目录 | Linux 相近目录或用途 |
|---|---|
| `C:\` | `/` 根目录 |
| `C:\Windows` | `/usr`、`/boot`、`/lib` 等系统级目录的组合 |
| `C:\Program Files` | `/opt`、`/usr` 或软件安装目录 |
| `C:\ProgramData` | `/var`、`/var/lib` |
| `C:\Users\用户名` | `/home/用户名` |
| `C:\Users\用户名\Desktop` | `~/Desktop` |
| `C:\Users\用户名\Documents` | `~/Documents` |
| `C:\Users\用户名\Downloads` | `~/Downloads` |
| `C:\Users\用户名\AppData\Roaming` | `~/.config`、`~/.local/share` |
| `C:\Users\用户名\AppData\Local` | `~/.local`、`~/.cache` |
| `C:\Users\用户名\AppData\LocalLow` | 低权限的用户级数据目录 |
| `C:\Windows\System32` | `/lib`、`/usr/lib`、`/usr/bin` |
| `C:\Windows\Temp` | `/tmp` |
| `C:\Users\用户名\AppData\Roaming\Microsoft\Windows\Start Menu` | `~/.local/share/applications` 或桌面启动项 |

## 5. 用户与系统权限的区别

Linux 通常使用用户和用户组管理权限，常见为：

```text
/root：管理员的根目录
/home/用户名：普通用户目录
/usr：系统软件目录
/var：运行时数据和日志
/tmp：临时文件
```

Windows 同样使用用户和权限控制，但用户数据通常集中在：

```text
C:\Users\用户名
```

普通用户可以访问自己的个人目录，而系统文件和其他用户的数据通常受到权限保护。系统级目录由管理员权限控制，普通用户通常不能随意修改。

## 6. 总结

Windows 的目录结构可以大致理解为：

```text
C:\
├── Windows：系统核心与组件
├── Program Files：程序安装目录
├── ProgramData：所有用户共享的数据
├── Users：所有用户主目录
│   └── 用户名：用户个人目录
│       ├── Desktop：桌面
│       ├── Documents：文档
│       ├── Downloads：下载
│       ├── Pictures：图片
│       ├── Videos：视频
│       └── AppData：应用配置、缓存与数据
└── PerfLogs：系统日志
```

对应 Linux 目录结构时，可以简单理解为：

```text
Windows 根目录 C:\        → Linux 根目录 /
Windows 系统目录           → Linux 系统目录和软件目录
Program Files              → /opt 或 /usr
Users\用户名               → /home/用户名
ProgramData                → /var
AppData\Roaming            → ~/.config
AppData\Local              → ~/.local 或 ~/.cache
Windows\System32           → /usr/lib、/lib
Windows\Temp               → /tmp
```

因此，Windows 用户目录更接近 Linux 的 `/home/用户名`，应用数据则类似 Linux 的隐藏配置目录；Windows 系统目录则由多个系统级目录组成，并不能简单等同于单个 Linux 目录。

## 命令行参数
### 修饰符
修饰符必须和参数编号绑定，不能单独存在。完整的语法规则是：
```
%~[修饰符组合] [参数编号]
   ↑            ↑
   ↑            └── 必填！必须是数字（0-9）或 *，代表第几个参数
   └── 可选修饰符（可组合），但绝不能脱离参数单独使用
```
#### CMD 完整参数修饰符对照表
| 修饰符 | 含义 | 示例（假设 `%0` = `E:\工具包\hello.cmd`） |
|---|---|---|
| `~d` | 盘符（Drive，仅盘符+冒号） | `E:` |
| `~p` | 目录（Path，不含盘符、文件名） | `\工具包\` |
| `~n` | 文件名（Name，不含扩展名） | `hello` |
| `~x` | 扩展名（eXtension，含点号） | `.cmd` |
| `~f` | 完整绝对路径（Full，含所有） | `E:\工具包\hello.cmd` |
| `~i` | 文件属性信息 | （略，较少用） |
| `~z` | 文件大小（字节） | （略，较少用） |
| `~t` | 文件时间戳 | （略，较少用） |
| `~a` | 文件属性（只读/隐藏等） | （略，较少用） |
| `~s` | 短路径（8.3格式，无空格） | （略，较少用） |
| `~$PATH` | 在 PATH 中查找参数对应的可执行文件 | （极少用） |

#### 测试脚本及运行效果示例
```cmd
@echo off
echo ========== 单修饰符测试（扩展 %0 = 脚本自身） ==========
echo 原始 %0      = "%~0"
echo ~d 盘符      = "%~d0"
echo ~p 目录      = "%~p0"
echo ~n 文件名    = "%~n0"
echo ~x 扩展名    = "%~x0"
echo ~f 完整路径  = "%~f0"

echo.
echo ========== 组合修饰符测试 ==========
echo ~dp  盘符+目录 = "%~dp0"
echo ~nx  文件名+扩展名 = "%~nx0"
echo ~fn  完整路径+文件名 = "%~fn0"

echo.
echo ========== 带真实参数测试 ==========
echo 请用 hello.cmd "C:\Users\test file.txt" 测试，或直接看下面的说明：
echo %1  = 第一个传入参数（脚本调用时的位置参数）
echo 若传入 "C:\Users\test file.txt"：
echo   %~d1 = "%~d1"（盘符）
echo   %~p1 = "%~p1"（目录）
echo   %~n1 = "%~n1"（文件名）
echo   %~x1 = "%~x1"（扩展名）

pause
```
运行效果示例：
```
========== 单修饰符测试 ==========
原始 %0      = "F:\U盘交接工具包\日常入口\hello.cmd"
~d 盘符      = "F:"
~p 目录      = "\U盘交接工具包\日常入口\"
~n 文件名    = "hello"
~x 扩展名    = ".cmd"
~f 完整路径  = "F:\U盘交接工具包\日常入口\hello.cmd"

========== 组合修饰符测试 ==========
~dp  盘符+目录 = "F:\U盘交接工具包\日常入口\"
~nx  文件名+扩展名 = "hello.cmd"
~fn  完整路径+文件名 = "F:\U盘交接工具包\日常入口\hello"
```

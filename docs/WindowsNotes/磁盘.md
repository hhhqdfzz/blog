## Windows 磁盘管理概念

```mermaid
---
config:
  layout: elk
  look: handDrawn
  theme: default
---
flowchart TD
    USB([USB设备])
    subgraph L1["第1层 物理层 插上了吗？<br>肉眼看是"]
        PHY_Y("插上了")
        PHY_N("没插上")
        PHY_Y -->|"物理拔出"| PHY_N
        PHY_N -->|"物理插入"| PHY_Y
    end

    subgraph L2["第2层 PnP节点层 设备认为插上了吗？<br>Get-PnpDevice 或 lsusb"]
        PNP_Y("是")
        PNP_N("否")
        PNP_Y -->|"Disable-PnpDevice<br>或 modprobe -r usb_storage"| PNP_N
        PNP_N -->|"Enable-PnpDevice<br>或 modprobe usb_storage"| PNP_Y
    end

    subgraph L3["第3层 盘符层 挂载了吗？<br>Get-Volume 或 lsblk"]
        MT_Y("是")
        MT_N("否")
        MT_Y -->|"Remove-PartitionAccessPath -AccessPath F:\\<br>或 umount"| MT_N
        MT_N -->|"Set-Partition -NewDriveLetter F<br>或 mount"| MT_Y
    end
	FILE([文件资源管理器可读])

    USB --> L1
    PHY_Y --> L2
    PNP_Y --> L3
	MT_Y --> FILE
```

## 插入 U 盘的 GUI 行为（自动播放）
windows系统中，每次插入U盘都会弹出一个文件资源管理器窗口，但我习惯在同一个窗口的不同标签页使用文件资源管理器，不想在插入U盘时弹出新窗口，更希望是以系统通知的形式提醒我。实现方法为：
1. `Win + I` 打开设置
2. Win11：蓝牙和其他设备 → 自动播放
   Win10：设备 → 自动播放
3. 打开「在所有媒体和设备上使用自动播放」总开关
4. 可移动驱动器下拉框，选择：**每次都询问我**
5. 点右下角**保存**
    - **每次都询问我**：插入U盘后，在「此电脑」增加盘符，弹出右下角Toast通知，不会自动打开新窗口，你点通知才会打开U盘的文件资源管理器。
    - **不执行任何操作**：插入U盘完全没有通知，仅默默在「此电脑」增加盘符。
6. 点右下角**保存**。

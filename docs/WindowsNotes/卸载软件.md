要彻底将一个软件删除干净，除了运行其自带的卸载程序外，通常还需要手动清理以下四个核心区域的文件和注册表残留：
## 1. 核心文件夹与配置路径
软件在运行期间会在多个系统隐藏目录下生成缓存、日志和个人配置。需要重点检查并删除以下路径：

* 应用专属数据 (AppData)：按下 Win + R 输入以下命令分别进入，并删除带有该软件名称的文件夹。
* %appdata%（对应 Roaming 文件夹，多存储用户个性化配置）
   * %localappdata%（对应 Local 文件夹，多存储缓存、本地临时文件）
* 程序安装根目录：通常在 C:\Program Files 或 C:\Program Files (x86)。
* 公共数据：按下 Win + R 输入 %programdata%（对应 ProgramData 文件夹，存储所有用户共享的软件数据）。
* 用户文档目录：部分软件会在 C:\Users\用户名\Documents（我的文档）下创建独立的文件夹。

## 2. Windows 注册表残留
软件的激活信息、右键菜单快捷方式、文件关联等通常写在注册表中。

* 查找路径：按下 Win + R 输入 regedit 打开[Windows 注册表编辑器](https://support.microsoft.com/zh-cn/windows/%E5%A6%82%E4%BD%95%E5%9C%A8-windows-%E4%B8%AD%E5%A4%87%E4%BB%BD%E5%92%8C%E6%81%A2%E5%A4%8D%E6%B3%A8%E5%86%8C%E8%A1%A8-855140ad-e318-2a13-2829-d428a2ab0692)。
* 清理位置：重点删除以下两处带有该软件或开发商名称的项（项即左侧的文件夹图标）：
* HKEY_CURRENT_USER\Software\
   * HKEY_LOCAL_MACHINE\SOFTWARE\
* 注意：修改注册表前，请务必右键点击目标文件夹选择“导出”进行备份，以防系统出错。

## 3. 系统服务与自启动项
有些软件卸载后，其后台常驻服务或自动更新程序依然在运行。

* 删除残留服务：以管理员身份运行命令提示符（CMD），输入 sc delete "服务名称" 彻底删除。
* 清理自启动任务：按下 Ctrl + Shift + Esc 打开任务管理器，检查“启动应用”选项卡，禁用不需要的残留启动项。
